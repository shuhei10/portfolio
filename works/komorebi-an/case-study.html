旅館サイト (森の宿 こもれび庵)

静寂と癒やしを伝えるブランドサイト

Role

Design / Front-end

Tech Stack

HTML, CSS, JavaScript

Duration

約2週間

Link

Live Demo →

プロジェクトの概要

森の中に佇む静かな宿の魅力を伝えるためのブランドサイト兼LPです。スマートフォンの普及に合わせ、どのデバイスから見ても美しいレスポンシブデザインを実現しました。

ビジュアルストーリー

文字情報を絞り、高品質な画像を大きく配置することで、「宿泊体験」を疑似的に体験できる構成にしています。余白を活かしたレイアウトにより、宿が提供する時間の流れの遅さを表現しました。

実装のポイント

パフォーマンスの最適化
高画質な画像を多用するため、次世代画像フォーマットの採用や遅延読み込み（lazy loading）を徹底し、高速なロード時間を実現しました。

予約導線の強化
ユーザーの宿泊意欲が高まったタイミングで迷わず予約ページへ誘導できるよう、スクロールに追従する予約ボタンを設置しています。

宿泊・観光サイトの制作

場所の魅力を引き出し、予約に繋げるサイト制作を得意としています。
