ブランドサイト (Aerblu)

ミニマリズムが際立つモダンな1ページ構成

Role

Design / Front-end

Tech Stack

HTML, CSS

Duration

約1週間

Link

Live Demo →

プロジェクトの概要

「洗練されたシンプルさ」を追求した架空ブランド「Aerblu」のポートフォリオ用デモサイトです。情報を極限まで削ぎ落とし、タイポグラフィと空白の美しさを前面に出したデザインを特徴としています。

デザインの意図

グリッドシステムを意識しつつも、あえて崩したレイアウトを採用することで、モダンかつファッショナブルな雰囲気を演出しました。フォントの選択一つひとつにこだわり、プロダクトの質感を視覚的に伝えています。

制作のポイント

CSSレイアウトの限界への挑戦
複雑なグリッド配置をFlexboxとCSS Gridのみで構築。フレームワークに頼らず、軽量でかつ柔軟なレスポンシブ表示を実現しました。

デザイン重視のサイト制作

細部までこだわり抜いた、唯一無二のWebサイトをご提案します。
